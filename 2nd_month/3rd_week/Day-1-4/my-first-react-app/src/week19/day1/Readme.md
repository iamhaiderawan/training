# Week 9 - Day 1: What is React?

## What I Learned

- React is a JavaScript library for building user interfaces
- It was created by Facebook and open-sourced in 2013
- UI is built from components — small, reusable JavaScript functions
- React is declarative — you describe what to show, React handles updates
- Virtual DOM makes React efficient — only changed parts get updated
- React is not a full framework, it handles the View layer only
