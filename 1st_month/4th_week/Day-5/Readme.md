📌 Overview

This project is a basic interactive web application built using HTML, CSS, and JavaScript (DOM manipulation).

The main goal of this code is to demonstrate how JavaScript can:

- Read user input from the page

- React to user actions (events)

- Process logic using a function

- Update the webpage dynamically without reloading

In simple words:

The browser page is not static anymore — JavaScript makes it alive.

🧠 What the Main Function Does

The core function in this project works like a controller between the user and the webpage.

Step-by-step behavior:

User performs an action
(example: clicking a button / submitting form / typing text)

JavaScript catches the event
using an event listener

The function runs

The function:

- Gets data from input fields

- Checks conditions / validation

- Processes the data

- Updates the HTML content

The page changes instantly
(text, result message, warning, or calculation output)

Flow of the Program

User Action → Event Listener → Function Runs → Data Processed → Page Updated

DOM Concepts

JavaScript Logic
