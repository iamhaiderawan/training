🔹 What are Conditions?

Conditions allow your program to make decisions based on situations.

Example:

If it is raining → take an umbrella
Else → don’t take an umbrella.

🔹 Basic if Statement
if (condition) {
// code runs if condition is true
}

Example:

let age = 20;

if (age >= 18) {
alert("You are an adult.");
}

🔹 if...else Statement
if (condition) {
// runs if true
} else {
// runs if false
}

Example:

let marks = 45;

if (marks >= 50) {
alert("Pass");
} else {
alert("Fail");
}

🔹 else if (Multiple Conditions)
let score = 85;

if (score >= 90) {
alert("Grade: A+");
} else if (score >= 80) {
alert("Grade: A");
} else if (score >= 70) {
alert("Grade: B");
} else {
alert("Grade: C");
}
