🔹 What is JavaScript?

JavaScript (JS) is a programming language used to make websites interactive.

HTML → Structure
CSS → Design
JavaScript → Behavior (actions, logic, interactivity)

Examples of what JS can do:

Show alerts

Change text or colors

Validate forms

Respond to button clicks

🔹 Where does JavaScript run?

In the browser (most common)

On the server (with Node.js)

🔹 How to write JavaScript in HTML?
Inline (not recommended):
<button onclick="alert('Hello!')">Click Me</button>

Internal JS:

<script>
  alert("Hello from JavaScript!");
</script>

External JS (Best Practice):

<script src="script.js"></script>

🔹 Variables in JavaScript

Variables store data.

Three ways to declare variables:
var name = "Ali"; // old way (avoid)
let age = 22; // modern, changeable
const country = "Pakistan"; // constant, cannot change

🔹 Data Types in JavaScript
1 String (text)
let name = "Ali";

2 Number
let age = 22;
let price = 1500.5;

3 Boolean (true/false)
let isStudent = true;

4 Undefined
let result;

5 Null
let data = null;
