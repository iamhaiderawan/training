What is the Box Model?

Every HTML element is treated as a box in CSS.
That box has 4 parts (from inside to outside):

- Content – The text or image

- Padding – Space inside the box (around the content)

- Border – The line around the padding

- Margin – Space outside the box (distance from other elements)

Think of it like:
Text → Padding → Border → Margin

Key Concepts You Must Remember:
🔹 Margin

Space outside the element.

margin: 20px;

🔹 Padding

Space inside the element, between content and border.

padding: 15px;

🔹 Border

Line around the element.

border: 2px solid black;x
