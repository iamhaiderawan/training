HTML Table Colspan & Rowspan HTML tables can have cells that span over multiple rows and/or columns. HTML Table - Colspan To make a cell span over multiple columns, use the colspan attribute: Example
Name Age
Jill Smith 43
Eve Jackson 57

Note: The value of the colspan attribute represents the number of columns to span. HTML Table - Rowspan To make a cell span over multiple rows, use the rowspan attribute: Example
Name Jill
Phone 555-1234
555-8745
